# CLI reference

Generated by `go run ./cmd/debux-docs`; do not edit by hand.

## `debux`

Debug any Docker or Kubernetes container

```text
debux [target] [-- command...] [flags]
```

| Flag | Default | Description |
|---|---|---|
| `--image` | `` | Debug image (default ghcr.io/clement-tourriere/debux:latest) |
| `--fresh` | `false` | Create a fresh debug container instead of reusing an existing debux session |
| `--no-volumes` | `false` | Do not directly mount target volumes (not a security boundary if /proc/1/root is accessible) |
| `--read-only-volumes` | `false` | Mount target volumes read-only in the debug container |
| `--user` | `` | Run debug container as uid[:gid] |
| `--privileged` | `false` | Run privileged (Docker); Kubernetes alias for --profile=sysadmin |
| `--copy` | `false` | Kubernetes: use a temporary copied pod instead of an ephemeral container |
| `--keep` | `false` | Kubernetes: with --copy, keep the copy pod after the session ends (reattach by targeting it, delete with debux kill) |
| `--ttl` | `24h` | Kubernetes: with --copy, kubelet-enforced deadline after which the copy pod is stopped (Go duration; 0 disables) |
| `--pull-policy` | `` | Image pull policy for the debug image (Always, IfNotPresent, Never) |
| `--profile` | `general` | Kubernetes: security profile (general, baseline, restricted, netadmin, sysadmin) |
| `--env` | `[]` | Extra KEY=VALUE environment for the debug container (repeatable) |
| `--cap-add` | `[]` | Extra Linux capability for the debug container (repeatable) |
| `--tools` | `[]` | Tool set name from the config file, or tool names (optionally name@version), auto-installed at session start (repeatable) |
| `--kubeconfig` | `` | Kubernetes: kubeconfig path |
| `--context` | `` | Kubernetes: kube context name |
| `--namespace, -n` | `` | Kubernetes: namespace |
